# تطبيق المهام

تطبيق مهام بسيط وأنيق مبني بـ Next.js و TypeScript و Tailwind CSS.

</div>

## الميزات
- إضافة المهام — اكتب واضغط Enter
- وضع علامة مكتمل — انقر على مربع الاختيار
- حذف المهام — مرر المؤشر وانقر X
- تصفية — الكل / النشط / المكتمل
- الوضع الداكن — واجهة داكنة جميلة افتراضياً
- التخزين المحلي — تستمر المهام عبر جلسات المتصفح

## البدء السريع
```bash
git clone https://github.com/mayakilzy/todo-app.git
cd todo-app
npm install
npm run dev
```
